# Photon 카드게임 MVP (한국어 설명)

이 프로젝트는 **Unity + Photon PUN2**를 사용한  
턴제 카드게임 최소 구현(MVP)입니다.

그래픽이나 연출보다 **네트워크 구조와 동기화 안정성**을
명확하게 보여주는 것을 목표로 제작되었습니다.

## 제작 목적
- Host 권한 기반(Authoritative) 게임 구조 증명
- 서버 시간 기반 턴 동기화 구현
- 정보 비대칭(상대 카드 비공개) 처리
- 멀티플레이 결과의 일관성 보장

## 핵심 특징
- 모든 승패 및 점수 계산은 Host에서만 처리
- PhotonNetwork.Time 기반 턴 타이머
- 카드 공개 전까지 상대 카드 정보 미전송
- 단순하지만 결정적인 규칙 구조
- 연결 종료 시 기본 처리 로직 포함

## 카드 규칙 요약
- 각 플레이어는 5장의 카드 보유
  - 왕 덱: 왕 1장, 시민 4장
  - 노예 덱: 노예 1장, 시민 4장
- 왕은 시민을 이김
- 시민은 노예를 이김
- 노예는 왕을 이김
- 10점을 먼저 달성하면 승리

## 턴 진행 구조
1. 카드 선택 및 제출 단계
2. Host 기준 동시 공개
3. 점수 계산 및 동기화
4. 다음 턴 준비

## 구조 설계 요약
- GameNetworkManager: Photon 연결 및 룸 관리
- TurnCoordinator: 턴 상태 관리 및 결과 확정 (Host)
- MatchState / PlayerState: 게임 상태 데이터
- UIController: 카드 및 상태 UI
- DebugOverlay: 턴/네트워크 상태 확인용 UI

## 참고 사항
이 프로젝트는 **포트폴리오용 기술 샘플**이며  
콘텐츠 확장이나 상업적 완성도를 목표로 하지 않습니다.
