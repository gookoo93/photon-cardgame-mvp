# Photon Cardgame MVP

## Host-Authoritative 멀티플레이 아키텍처 설계 샘플

Unity + Photon PUN2

이 프로젝트는 2인 턴제 카드 게임 MVP로, 다음을 명확하게 증명하기 위해
제작되었습니다:

-   정확한 멀티플레이 동기화
-   권한 분리 설계
-   히든 정보 처리의 안정성

본 프로젝트는 그래픽 완성도나 콘텐츠 볼륨보다 네트워크 정확성과 아키텍처
설계의 명확성에 집중합니다.

------------------------------------------------------------------------

## 프로젝트 목적

이 프로젝트는 단순 게임 구현이 아닌, 네트워크 설계 중심의 포트폴리오
샘플입니다.

주요 목표:

-   엄격한 Host-Authoritative 멀티플레이 구조
-   결정론적 결과 계산
-   히든 정보 보호 설계
-   상태 동기화 제어
-   재접속 유예 처리 로직
-   네트워크 로직과 UI의 명확한 분리

------------------------------------------------------------------------

## 핵심 네트워크 설계 철학

### 권한 구조

본 프로젝트는 철저한 Host-Authoritative 구조를 따릅니다.

#### 마스터 클라이언트 (Host)

-   경기 결과 계산
-   점수 갱신
-   상태 전이 제어
-   재접속 유예 타이머 관리
-   게임 종료 결정

#### 클라이언트

-   입력만 전송
-   로컬에서 결과 계산을 절대 수행하지 않음
-   RPC 수신 후 UI만 갱신

### 이를 통해 방지되는 문제

-   점수 불일치
-   중복 실행 버그
-   지연 환경에서의 desync
-   클라이언트 치팅 가능성

------------------------------------------------------------------------

## 히든 정보 처리

카드 제출 단계와 공개 단계를 명확히 분리했습니다.

### 제출 단계

-   각 플레이어는 자신의 카드만 RPC로 전송
-   상대 카드 정보는 노출되지 않음

### 공개 단계

-   Host가 공개 RPC를 트리거
-   양쪽 카드가 동시에 공개

공개 전까지 상대 카드 정보는 절대 전송되지 않습니다.

------------------------------------------------------------------------

## 상태 동기화 전략

### 상태 머신

WaitingForPlayers\
→ Round_Pick\
→ Round_Reveal\
→ Round_Result\
→ Winner_Choose\
→ Game_End

모든 상태 전이는 Host가 결정합니다.

### 사용 기술

-   RPC_BroadcastReveal
-   RPC_BroadcastResult
-   RPC_SyncStateToRejoin
-   PhotonNetwork.Time (페이즈 기준 시간)

클라이언트는 상태 수신자 역할만 수행합니다.

------------------------------------------------------------------------

## 재접속 및 이탈 처리

### 게스트 이탈

-   Host가 60초 재접속 유예 타이머 시작
-   재접속 성공 시:
    -   RPC_SyncStateToRejoin으로 전체 상태 동기화
-   시간 초과 시:
    -   RPC_ForceResetToWaiting으로 초기화

### 호스트 이탈

-   권한 유지 불가
-   OnMasterClientSwitched 발생 시 즉시 종료 처리
-   클라이언트는 로비로 이동
-   사용자에게 안내 UI 표시

불완전한 권한 상태를 방지합니다.

## 아키텍처 개요

### 씬 흐름

PhotonBootstrap (DontDestroyOnLoad) ↓ TitleManager ↓ LobbyManager ↓
GameManager (Host Authority)

------------------------------------------------------------------------

## 주요 구성 요소

### PhotonBootstrap

-   서버 연결 전담
-   예기치 않은 연결 끊김 시 자동 재연결
-   AutomaticallySyncScene 활성화

### LobbyManager

-   방 목록 캐싱
-   검색 및 필터 기능
-   공개 / 비공개 방 처리
-   CustomProperties 활용 (title, code, password)

### GameManager

-   상태 머신 관리
-   권한 분리 설계
-   결정론적 결과 계산
-   재접속 처리 로직
-   승자 역할 선택 로직

### HandCardButton

-   카드 선택 로직
-   키 카드 동적 교체
-   시각 상태 처리

------------------------------------------------------------------------

## 게임 규칙 (단순화 버전)

각 플레이어는 5장의 카드를 가집니다.

### King 덱

-   King 1장
-   Citizen 4장

### Slave 덱

-   Slave 1장
-   Citizen 4장

규칙:

-   King은 Citizen을 이깁니다
-   Citizen은 Slave를 이깁니다
-   Slave는 King을 이깁니다

먼저 10점을 달성한 플레이어가 승리합니다.

## 이 프로젝트가 증명하는 것

본 프로젝트는 다음 역량을 보여줍니다:

-   멀티플레이 권한 구조 설계 능력
-   클라이언트 desync 방지 설계
-   상태 복구 처리 설계
-   UI와 게임 로직의 분리
-   결정론적 매치 시스템 구축
-   안전한 이탈 처리
-   Photon PUN의 단순 사용을 넘는 구조 설계
